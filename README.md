# LuminaRead Pro — Кроссплатформенная читалка и загрузчик книг (Java 17+)

**LuminaRead** — настольное приложение на Java для **macOS (MacBook Air / Pro на Apple Silicon и Intel)**, **Windows** и **Linux**, объединяющее минималистичный дизайн, все ключевые возможности **Moon+ Reader Pro** и встроенный загрузчик книг из онлайн-библиотек и OPDS-каталогов.

> **Требования:** установленная **Java 17 или новее** (рекомендуется Temurin JDK/JRE 17+ или 21 — https://adoptium.net/). Архив уже собран под **Java 17** и запускается на **Windows 10/11** (Home/Pro/Enterprise, x64), macOS и Linux.

## Как запустить за 1 секунду

В архив уже включен готовый скомпилированный файл **`LuminaRead.jar`** и полный исходный код:

* **На macOS**: дважды кликните по файлу **`Start_LuminaRead_Mac.command`** или **`LuminaRead.jar`**, либо выполните в Терминале:
  ```bash
  java -jar LuminaRead.jar
  ```
* **На Windows (10 / 11)**: дважды кликните по файлу **`Start_LuminaRead_Windows.bat`** (автоматически проверяет Java, настраивает UTF-8 и сглаживание шрифтов) или запустите **`LuminaRead.jar`**.
* **На Linux (Ubuntu, Debian, Fedora, Arch)**: запустите скрипт **`Start_LuminaRead_Linux.sh`** (автоматически проверяет наличие Java 17+, графического интерфейса и сглаживания текста):
  ```bash
  chmod +x Start_LuminaRead_Linux.sh
  ./Start_LuminaRead_Linux.sh
  ```
  Или запустите напрямую через Java:
  ```bash
  java -Dawt.useSystemAAFontSettings=on -Dswing.aatext=true -Dfile.encoding=UTF-8 -jar LuminaRead.jar
  ```
* **В IntelliJ IDEA / Eclipse / VS Code**: откройте папку проекта как Maven-проект (`pom.xml`) и запустите класс `com.luminaread.LuminaReadApp`.

## Основные возможности

1. **Мультиформатный движок чтения**:
   * **FB2 и FB2.ZIP** — полная поддержка структуры глав `<section>`, эпиграфов, стихов `<poem>`, сносок и встроенных обложек/иллюстраций `<binary>`.
   * **EPUB (EPUB 2 и EPUB 3)** — чтение `container.xml`, манифеста `.opf`, порядка глав `<spine>`, оглавления NCX и встроенных иллюстраций.
   * **TXT, Markdown (.md), HTML, RTF** — автоматическое распознавание русских кодировок (**UTF-8, Windows-1251, KOI8-R, UTF-16**) без «кракозябр» и умная разбивка на главы.
   * **CBZ** (архивы комиксов и манги) и **PDF** (извлечение текста и разделов).
2. **Дизайн и настройки уровня Moon+ Reader Pro**:
   * **6 цветовых тем**: *Чистый свет (Бумага)*, *Классическая сепия*, *Глубокая ночь (AMOLED)*, *Сумерки (Nord)*, *Электронные чернила (E-Ink)* и *Мятный комфорт (Защита глаз)*.
   * **Тонкая типографика**: выбор шрифта, кегля (`12–36 пт`), межстрочного интервала, полей страницы, выравнивания по ширине (`Justify`) и **двухколоночного книжного разворота**.
   * **2 режима чтения**: постраничное перелистывание и плавный вертикальный свиток (скролл).
   * **Управление жестами и 9 зон экрана**: клик слева/справа листает страницы, клик по центру включает **Дзен-режим без рамок (`F11`)**, а вертикальное движение мышью вдоль **левого края страницы** плавно регулирует яркость экрана + фильтр защиты зрения.
3. **Инструменты активного чтения**:
   * **Плавная автопрокрутка (Auto-scroll)** с регулировкой скорости.
   * **Голосовая озвучка книги (TTS)** через нативный синтезатор речи (`say` на macOS, `System.Speech` / PowerShell на Windows, `espeak` / `spd-say` на Linux) со встроенным **таймером сна** (15, 30, 60 мин).
   * **Закладки, цветные цитаты (4 цвета маркера) и заметки** с подсветкой прямо в тексте книги и выгрузкой конспекта в **Markdown (`.md`)**.
   * **Встроенный словарь и переводчик (RU ↔ EN)** + быстрый поиск по тексту книги.
4. **Онлайн-поиск и скачивание книг**:
   * Встроенный параллельный поиск по **Flibusta OPDS**, **Project Gutenberg (70 000+ книг)**, **Open Library / Internet Archive** и **Standard Ebooks**.
   * Поддержка подключения любых пользовательских OPDS-каталогов и прямого скачивания файлов книг по URL.
5. **Онлайн-манга и манхва** (раздел «Манга и Манхва»):
   * Поиск и чтение манги/манхвы по трём источникам: **MangaLib (RU)**, **Remanga (RU)** и **MangaDex (EN/RU)**.
   * Выбор языка глав (русский/английский), ридер в режимах «вебтун-лента» (бесшовный скролл) или «постранично» (листание ←/→).
   * Кнопки «предыдущая / следующая глава», отдельные списки избранной манги и истории чтения.
