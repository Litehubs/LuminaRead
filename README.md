# LuminaRead — книги, манга и ранобэ

**LuminaRead** — настольная библиотека и читалка для **macOS**, **Windows** и **Linux**. Храните книги, читайте мангу и ранобэ и скачивайте книги из онлайн-библиотек и OPDS-каталогов.

## Установка и запуск

Готовые установщики для Windows и Linux будут доступны на странице релиза.
Выберите файл из списка **Assets**. Java входит в оба пакета. [Скачать LuminaRead](https://github.com/Litehubs/LuminaRead/releases/latest)

| Система | Файл | Установка |
| --- | --- | --- |
| Windows x64 | `LuminaRead-…-windows-x64.exe` | Откройте установщик, затем запустите **LuminaRead** из меню «Пуск». |
| Ubuntu / Debian amd64 | `LuminaRead-…-linux-amd64.deb` | Откройте пакет через установщик приложений или выполните `sudo apt install ./имя-файла.deb`, подставив скачанное имя. Затем откройте **LuminaRead** из меню приложений. |

Пакет Linux проверяется на Ubuntu 22.04 и Debian 12. На Windows неподписанный установщик может вызвать предупреждение SmartScreen. Скачивайте установщик со страницы проекта и сверяйте его SHA-256 с файлом `SHA256SUMS` из того же релиза. [О SmartScreen](https://learn.microsoft.com/windows/apps/package-and-deploy/smartscreen-reputation)

### Запуск JAR на macOS или другой системе

Установите Java 17 или новее и скачайте `LuminaRead.jar` из раздела **Assets** на странице релиза. Откройте терминал в папке со скачанным файлом и запустите приложение. [Установка Java](https://adoptium.net/installation) · [Скачать LuminaRead](https://github.com/Litehubs/LuminaRead/releases/latest)

```text
java -version
java -jar LuminaRead.jar
```

### PDF и озвучка

- Текстовый слой PDF читается встроенным движком. Для сканов без текстового слоя на Windows и Linux нужно предварительно распознать текст. На macOS приложение также отображает изображения страниц через PDFKit.
- Для озвучки на Windows используется Windows PowerShell (`powershell.exe`) с `System.Speech`. На Linux нужна команда `espeak` или `spd-say`.

## Сборка из исходников

Для сборки нужны **JDK 17 или новее** и **Maven**. Из корня проекта в PowerShell или терминале выполните:

```text
mvn -v
mvn clean verify
java -jar target/LuminaRead.jar
```

Проверьте, что `mvn -v` показывает Java 17 или новее. Maven запускает тесты и включает библиотеки приложения в JAR. Для первой сборки требуется доступ к Maven Central.

В исходниках также есть скрипты запуска. На Windows можно открыть `Start_LuminaRead_Windows.bat`, на Linux выполнить `bash Start_LuminaRead_Linux.sh`, на macOS открыть `Start_LuminaRead_Mac.command`. Скрипты сначала ищут `target/LuminaRead.jar`. Для запуска скачанной сборки через скрипт поместите JAR рядом с ним под именем `LuminaRead.jar`.

В IntelliJ IDEA, Eclipse или VS Code откройте папку как Maven-проект и запустите `com.luminaread.LuminaReadApp`.

## Вход через Яндекс ID

LuminaRead открывает вход в системном браузере и получает одноразовый код через локальный адрес. Профиль можно удалить в настройках. После перезапуска профиль отображается как сохранённый и доступно повторное подтверждение в браузере. OAuth-токены на диск не записываются.

Для своего OAuth-приложения укажите Redirect URI `http://127.0.0.1:49321/oauth/yandex/callback` и задайте публичный Client ID через `-Dyandex.client.id=...`, переменную `YANDEX_CLIENT_ID` или параметр `yandex.client.id` в `~/.luminaread/auth.properties`. Для обмена кода используется PKCE, поэтому клиентский секрет не требуется.

## Основные возможности

1. **Мультиформатный движок чтения**:
   * **FB2 и FB2.ZIP** — поддержка структуры глав `<section>`, эпиграфов, стихов `<poem>`, сносок и встроенных обложек/иллюстраций `<binary>`.
   * **EPUB (EPUB 2 и EPUB 3)** — чтение `container.xml`, манифеста `.opf`, порядка глав `<spine>`, оглавления NCX и встроенных иллюстраций.
   * **TXT, Markdown (.md), HTML, RTF** — распознавание кодировок (**UTF-8, Windows-1251, KOI8-R, UTF-16**) и разбивка на главы.
   * **CBZ** (архивы комиксов и манги) и **PDF** (извлечение текста и отображение страниц через PDFKit на macOS).
2. **Дизайн и настройки чтения**:
   * **Анимации чтения** при открытии и закрытии читалки, смене разделов и темы, а также при ручном перелистывании книги. Их можно отключить в разделе «Настройки и загрузки».
   * **6 цветовых тем**: *Чистый свет*, *Классическая сепия*, *Глубокая ночь*, *Сумерки*, *Электронные чернила* и *Мятный комфорт*.
   * **Тонкая типографика**: выбор шрифта, кегля (`12–36 пт`), межстрочного интервала, полей страницы, выравнивания по ширине (`Justify`) и **двухколоночного книжного разворота**.
   * **2 режима чтения**: постраничное перелистывание и плавный вертикальный свиток (скролл).
   * **Управление мышью**: клик слева/справа листает страницы, клик по центру включает **Дзен-режим без рамок (`F11`)**, а вертикальное движение мышью вдоль **левого края страницы** плавно регулирует яркость экрана + фильтр защиты зрения.
3. **Инструменты активного чтения**:
   * **Плавная автопрокрутка (Auto-scroll)** с регулировкой скорости.
   * **Голосовая озвучка книги (TTS)** через нативный синтезатор речи (`say` на macOS, `System.Speech` / PowerShell на Windows, `espeak` / `spd-say` на Linux) со встроенным **таймером сна** (15, 30, 60 мин).
   * **Закладки, цветные цитаты (4 цвета маркера) и заметки** с подсветкой прямо в тексте книги и выгрузкой конспекта в **Markdown (`.md`)**.
   * **Встроенный словарь и переводчик (RU ↔ EN)** + быстрый поиск по тексту книги.
4. **Онлайн-поиск и скачивание книг**:
   * Встроенный параллельный поиск по **Flibusta OPDS**, **Project Gutenberg**, **Open Library / Internet Archive** и **Standard Ebooks**.
   * Поддержка подключения пользовательских OPDS-каталогов и прямого скачивания файлов книг по URL.
5. **Онлайн-манга и манхва** (раздел «Манга и Манхва»):
   * Поиск и чтение манги/манхвы по трём источникам: **MangaLib (RU)**, **Remanga (RU)** и **MangaDex (EN/RU)**.
   * Выбор языка глав (русский/английский), ридер в режимах «вебтун-лента» (бесшовный скролл) или «постранично» (листание ←/→).
   * Кнопки «предыдущая / следующая глава», отдельные списки избранной манги и истории чтения.
