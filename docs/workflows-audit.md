# Аудит загрузок и библиотеки — 17 ноября 2026

Проверены четыре задачи из [предыдущего аудита](development-audit.md).

| Задача | Результат |
| --- | --- |
| Восстановление загрузок | Готовый файл сохраняется по стабильному пути. При запуске очередь повторяет импорт без сетевого запроса. Если библиотека успела сохранить книгу до сбоя, очередь находит уже добавленную запись. Прерванная передача видна в истории, её можно начать заново. Ссылки на скачивание не сохраняются на диск. |
| Первый запрос каталогов | Манга и ранобэ получают популярное при первом переходе в свой раздел. Повторный вход использует текущие результаты. Кнопка поиска позволяет повторить запрос после ошибки. |
| Актуальность открытой книги | Перед использованием кэша проверяются путь, размер, времена файла и идентификатор, когда его отдаёт система. Изменившийся файл разбирается заново. Если файл переместили или удалили, читалка показывает ошибку открытия. Файл с нового пути можно импортировать заново. |
| Экспорт заметок | Символы Markdown, ссылки и HTML из заголовков, закладок и текста выводятся буквально. Цитаты и заметки сохраняют переносы, заголовки и подписи остаются однострочными. |

`mvn clean verify` выполнил 184 теста без падений. Проверен отдельный процесс,
завершённый сразу после реального скачивания, а также сбои в середине передачи
и между записью библиотеки и обновлением очереди. Сценарий видимого окна прошёл
на macOS с блокировкой внешней сети. Синтетический экспорт проверен в GitHub
Markdown и через Foundation на macOS.

Список загрузок и импорт координирует `LibraryDownloads`. `DownloadQueue` отвечает
за файлы восстановления, `NotesMarkdown` — за отображение данных в экспорте.
Эти части проверяются без окна, а Swing обновляет отображение по существующим
уведомлениям.

## Следующий этап

1. **Защита перенаправлений.** Клиенты поиска и загрузки книг используют
   `HttpClient.Redirect.ALWAYS`. Проверить цепочки с переходом с HTTPS на HTTP
   и запретить понижение протокола, сохранив работу явно указанных HTTP-каталогов.
2. **Аварийное завершение локального импорта.** При копировании локальной книги
   конечное имя резервируется созданием пустого файла. Проверить, что произойдёт
   при остановке процесса после резервирования и при одновременном импорте
   одного файла, затем сделать публикацию и очистку повторяемыми.
3. **Большая полка.** Поиск и смена фильтра перестраивают все карточки на EDT.
   Измерить задержку набора и число компонентов на библиотеке из нескольких тысяч
   книг. Ограничить объём обновления и проверить, что клавиатурный фокус
   сохраняется после поиска и возвращения из читалки.
