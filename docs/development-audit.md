Локально `mvn clean verify` выполнил 178 тестов. Отдельно прошли проверки с видимым
окном, больших документов, файлового профиля и сохранения большой библиотеки.

### Замеры интерфейса

Сценарий `MotionProbe` открывает библиотеку с 40 обложками в окне 1420 × 900,
восемь раз открывает и закрывает книгу и запускает последовательные перелистывания.
Флаг `-Dluminaread.motion.trace=true` выводит длительность снимка, синхронной части
перехода и отрисовки кадра в наносекундах. В видимом окне на Mac наблюдались масштабы
1× и 2×. Таблица показывает 95-й перцентиль одного прогона в миллисекундах.

| Масштаб | Снимок до → после | Синхронная часть перехода до → после | Кадр до → после |
| --- | --- | --- | --- |
| 1× | 7,8 → 8,0 | 17,5 → 17,8 | 4,1 → 7,1 |
| 2× | 7,7 → 10,5 | 23,5 → 24,2 | 33,6 → 31,6 |

На 2× отрисовка тяжёлых кадров всё ещё превышает 16 мс. Появление карточек
использует локальную заливку без снимка всего окна, а фокус и наведение сохраняют
видимость при отключённом движении. Размеры кэша и страницы PDF ограничены.
При исчерпании бюджета PDF использует извлечённый текст, когда он доступен.

## Новые задачи

1. **Восстановление очереди загрузок.** `OnlineCatalogService` хранит список задач в
   памяти. После перезапуска пользователь теряет сведения о завершённой загрузке,
   которая не дошла до импорта. Сохранить состояние передачи и импорта, сверять
   готовый файл при запуске и повторять импорт без второй загрузки. Проверить
   прерывание в каждой стадии и повторное открытие приложения.
2. **Загрузка каталогов при открытии раздела.** Основное окно запускает поиски
   манги и ранобэ сразу после открытия приложения. Перенести первую загрузку
   на вход в соответствующий раздел, сохранить повторный поиск по команде пользователя
   и проверить запуск без сети. Сценарий до входа в каталог должен выполняться без
   запросов к этим двум источникам.
3. **Актуальность книги после внешнего изменения файла.** Разобранное содержимое
   ищется в кэше по ID. Если другой редактор заменит исходный файл, открытие может
   вернуть прежний текст. Проверять, изменился ли источник, и перечитывать его через
   обычный загрузчик. Проверить замену, перемещение, удаление и повторный импорт.
4. **Корректный экспорт заметок.** Экспорт в Markdown вставляет заголовки, цитаты
   и заметки из библиотеки напрямую. Проверить, что переносы, символы Markdown
   и HTML из книги сохраняют структуру экспорта. Использовать проверяемые файлы
   для повторного открытия в нескольких Markdown просмотрщиках.

Для сетевой проверки использован транспорт с явным адресом соединения.
[Реализация установки адреса в Apache HttpClient](https://github.com/apache/httpcomponents-client/blob/rel/v5.6.4/httpclient5/src/main/java/org/apache/hc/client5/http/impl/io/DefaultHttpClientConnectionOperator.java).
