# Сборка установщиков LuminaRead

GitHub Actions проверяет приложение на Java 17, а установщики собирает с
Temurin JDK 25. Для ручной сборки нужен x64 компьютер с целевой ОС и PowerShell 7.
На Windows нужны WiX и ImageMagick, на Ubuntu нужны `fakeroot` и `dpkg-dev`.

```powershell
mvn clean verify
./packaging/build.ps1 -Type exe
```

На Linux используйте `./packaging/build.ps1 -Type deb`. Пакеты появляются в
`target/packaging/installers`. Скрипт `check-install.ps1` устанавливает пакет
на машине, на которой его запускают. CI выполняет его на одноразовых системах.

## Выпуск версии

1. Установите в Maven числовую версию `X.Y.Z`. Имя JAR остаётся постоянным,
   а имена установщиков и версия внутри них меняются вместе с `pom.xml`.
2. После слияния версии поставьте тег `vX.Y.Z` на нужный коммит и отправьте тег
   в GitHub. Установщики соберутся из этого коммита.
3. После проверок появится черновик релиза с двумя установщиками, JAR для
   macOS и других систем и файлом `SHA256SUMS`. Проверьте описание и
   опубликуйте релиз.

Для обновлений сохраняйте идентификатор Windows из `build.ps1` и имя Debian-пакета
`luminaread`. Новую версию можно установить поверх старой. Библиотека и настройки
хранятся в пользовательском профиле. Публикация сборки не обновляет установленную
программу автоматически.
